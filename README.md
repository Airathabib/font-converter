Font Converter Pro 🔤🎨

# Универсальный комбайн для веб-разработчика: конвертация шрифтов и генерация фавиконок.

# Приложение позволяет быстро конвертировать файлы шрифтов (.ttf, .otf, .woff) в веб-форматы (.woff, .woff2), а также генерировать полный набор фавиконок и манифестов для PWA из одного изображения.

🚀 Особенности
🔤 Конвертер шрифтов
🔄 Конвертация форматов: TTF / OTF / WOFF → WOFF / WOFF2.
✅ Валидация: Проверка сигнатур файлов перед конвертацией.
📥 Массовая обработка: Конвертация нескольких файлов за один раз.
🎨 Генератор фавиконок
🖼️ Поддержка форматов: PNG, JPG, JPEG, WebP, SVG → набор иконок.
📦 Полный пакет: Генерация favicon.ico, apple-touch-icon, android-chrome, site.webmanifest.
📋 Готовый код: Автоматическая генерация HTML-тегов для вставки в <head>.
🗜️ Оптимизация: Сжатие изображений через sharp без потери качества.
🌐 Общие возможности
🖥️ Кроссплатформенность: Работает на Windows как Desktop App.
🌓 Тёмная и светлая тема: Автоматическое переключение интерфейса.
🔒 Приватность: Все данные обрабатываются локально, ничего не отправляется в интернет.
⚡ Встроенный сервер: В собранной версии бэкенд работает внутри приложения — не требуется внешняя настройка.
📁 Портативность: Запускается с флешки, не требует установки.
🛠 Стек технологий

Проект построен на современном стеке Monorepo:

Компонент | Технологии
Frontend | React 18, TypeScript, Vite, SCSS Modules
Desktop | Electron 28
Backend | Node.js, Express, Multer, ttf2woff, ttf2woff2, favicons, sharp, adm-zip
Инструменты | npm Workspaces, Husky, Lint-staged, ESLint, Prettier

📦 Установка
Для работы с проектом вам потребуется Node.js (версия 18 или выше).
Клонируйте репозиторий:

git clone https://github.com/your-username/font-converter.git
cd font-converter

Установите зависимости для всего монорепозитория

npm install

💻 Запуск в режиме разработки (Dev Mode)
В режиме разработки Frontend и Backend запускаются как отдельные процессы для удобства отладки.
Вариант 1: Запуск всего одной командой (из корня)
Удобно, если вы хотите запустить всё сразу.

npm run dev

Вариант 2: Раздельный запуск (в разных терминалах)
Рекомендуется для отладки бэкенда и фронтенда по отдельности.
Терминал 1: Backend

cd backend
npm run dev

# Сервер запустится на http://localhost:3001

Терминал 2: Frontend (React + Vite)

cd frontend
npm run dev

# Приложение откроется в браузере на http://localhost:5173

**Примечание: В режиме разработки Electron не используется, фронтенд работает в браузере.**

🎨 Использование генератора фавиконок
Переключитесь на вкладку "🎨 Фавиконки" в интерфейсе приложения.
Загрузите изображение (рекомендуется квадратное PNG от 512×512 px).
Укажите название приложения (для site.webmanifest и мета-тегов).
Выберите форматы, которые нужно сгенерировать:
✅ favicon.ico — классическая иконка для браузеров
✅ apple-touch-icon.png — для iOS (домашний экран)
✅ android-chrome-192/512.png — для Android PWA
✅ favicon-32x32.png — стандартный размер
✅ mstile-150x150.png — для Windows Start
Нажмите "🚀 Сгенерировать".
Скачайте результат:
📦 ZIP-архив со всеми сгенерированными файлами
📋 HTML-код для вставки в <head> (кнопка "Копировать")
📁 Что внутри архива:

my-app-favicons.zip
├── favicon.ico
├── favicon-16x16.png
├── favicon-32x32.png
├── apple-touch-icon.png (180×180)
├── android-chrome-192x192.png
├── android-chrome-512x512.png
├── mstile-150x150.png
├── site.webmanifest # JSON-манифест для PWA
└── favicon-head.html # Готовые <link>-теги для вставки

📦 Сборка приложения (Production)
Сборка создает полноценное десктопное приложение с встроенным бэкендом.
Шаг 1: Подготовка файлов
Перед упаковкой нужно собрать исходный код фронтенда и Electron-части.

cd frontend
npm run build:frontend # Сборка React в папку dist/
npm run build:electron # Компиляция TS в папку dist-electron/

Шаг 2: Упаковка в приложение
Выполните скрипт ручной сборки (он создает папку dist-manual):

npm run package:manual

Шаг 3: Запуск готового приложения
После успешной сборки перейдите в папку результата:

cd frontend/dist-manual

Запустите приложение:

Windows: Дважды кликните по start.bat (или запустите через PowerShell: & .\start.bat).

✅ Приложение полностью автономно: бэкенд встроен, интернет не требуется.
