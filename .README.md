Недавно столкнулся с тем что не было нужных расширений шрифтов нигде и поэтому сделал свой небольшой конвертер. С расширениями и блэкджеком.
Font Converter Pro 🔤
Современное десктопное приложение для конвертации шрифтов.
Приложение позволяет веб-разработчикам и дизайнерам быстро конвертировать файлы шрифтов (.ttf, .otf, .woff) в веб-форматы (.woff, .woff2) с минимальными усилиями.
🚀 Особенности
🔄 Конвертация форматов: TTF / OTF → WOFF / WOFF2.
🖥️ Кроссплатформенность: Работает на Windows (Desktop App).
Темная и Светлая тема: Автоматическое переключение интерфейса.
🔒 Приватность: Все данные обрабатываются локально, ничего не отправляется в интернет.
⚡ Встроенный сервер: В собранной версии бэкенд работает внутри приложения, не требуя внешней настройки.
Стек технологий
Проект построен на современном стеке Monorepo:

Компонент | Технологии

Frontend | React 18, TypeScript, Vite, SCSS Modules
Desktop | Electron 28
Backend | Node.js, Express, Multer, ttf2woff, ttf2woff2
Инструменты | npm Workspaces, Husky, Lint-staged, ESLint

📦 Установка
Для работы с проектом вам потребуется Node.js (версия 18 или выше).
Клонируйте репозиторий:

git clone https://github.com/your-username/font-converter.git
cd font-converter

Установите зависимости для всего монорепозитория:
npm install

💻 Запуск в режиме разработки (Dev Mode)
В режиме разработки Frontend и Backend запускаются как отдельные процессы для удобства отладки.
Вариант 1: Запуск всего одной командой (из корня)
Удобно, если вы хотите запустить всё сразу.

npm run dev

Вариант 2: Раздельный запуск (в разных терминалах)
Рекомендуется для отладки бэкенда и фронтенда по отдельности.
Терминал 1: Backend
cd backend
npm run dev

# Сервер запустится на http://localhost:3001

Терминал 2: Frontend (React + Vite)

cd frontend
npm run dev

# Приложение откроется в браузере на http://localhost:5173

**Примечание: В режиме разработки Electron не используется, фронтенд работает в браузере.**

📦 Сборка приложения (Production)
Сборка создает полноценное десктопное приложение с встроенным бэкендом.
Шаг 1: Подготовка файлов
Перед упаковкой нужно собрать исходный код фронтенда и Electron-части.

cd frontend
npm run build:frontend # Сборка React в папку dist/
npm run build:electron # Компиляция TS в папку dist-electron/

Шаг 2: Упаковка в приложение
Выполните скрипт ручной сборки (он создает папку dist-manual):

npm run package:manual

Шаг 3: Запуск готового приложения
После успешной сборки перейдите в папку результата:

cd frontend/dist-manual

Запустите приложение:
Windows: Дважды кликните по start.bat (или запустите через PowerShell: & .\start.bat).
